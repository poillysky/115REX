## 1. 产品定位

**115REX = 115 网盘影视终端 + 资源整合搜索。**

- **115 网盘影视终端**：把 115 网盘里的文件变成一个「有元数据、有进度、有字幕、可播放」的影视库。
  视频始终留在 115，客户端拿短时直链直连播放，不下载、不转存到本地。
- **资源整合搜索**：把分散在多个来源的影视资源抽象成一次跨源搜索，结果可直接执行落地动作。

闭环：**搜索命中 → 转存到 115 → 刮削入库 → 在终端播放**。
无论资源从哪来，最终都收敛成影视库里的一条条目。

## 2. 典型场景

| 场景 | 路径 | 是否经过资源搜索 |
| --- | --- | --- |
| 已知片名，直接看 | 影视库 → 详情 → 播放 | 否 |
| 网盘里没有 | 搜索 → 候选 → 转存 → 入库 → 播放 | 是 |
| 找种子 / 找资源文件 | 搜索 → 候选 → 下载 / 推送 | 是 |
| 续播 | 影视库 / 继续观看 → 播放 | 否 |

## 3. 系统组成

| 层 | 技术 | 职责 | 不负责 |
| --- | --- | --- | --- |
| 客户端 | Web（与 App 并列的正式入口）+ Flutter App（iOS 为主） | 浏览、搜索、播放、进度、收藏 | 持有 115 凭据、访问资源源 |
| 控制面 | Python + FastAPI + SQLite | 鉴权、聚合搜索、动作编排、索引刮削、播放信息签发 | 转发视频字节 |
| 数据面 | 115 CDN | 视频 / 字幕 / 封面字节 | 业务逻辑 |

### 3.1 资源源清单

资源源是**外部依赖**，不是本项目的一部分。本项目只负责把它们适配成统一检索能力，并提供统一动作。

| 资源源 | 形态 | 接入方式（待实测确认） |
| --- | --- | --- |
| 自建资源库 | Postgres | 直连 PG 查询 |
| BitMagnet | 本地 BT 客户端 | 其 GraphQL 接口 |
| CloudSaver | 脚本化网盘资源服务 | HTTP 脚本接口 |
| semitio addon | 插件式资源源 | addon 目录脚本扩展 |
| 后续可插拔 | —— | 统一走 provider 注册表（[05](05-resource-search.md)） |

### 3.2 部署形态

| 端 | 部署 | 地址 |
| --- | --- | --- |
| 后端 | 用户自己的 Windows 机器 | `http://127.0.0.1:9959` |
| Web | 与后端同源托管 | 同上（生产免 CORS） |
| App | iOS 真机 / 模拟器 | 局域网地址；真机必须 HTTPS（ATS） |

## 4. 控制面 / 数据面边界

| | 控制面 | 数据面 |
| --- | --- | --- |
| 内容 | JSON 接口、鉴权、索引、进度 | 视频 / 字幕 / 封面字节 |
| 鉴权 | Bearer 令牌 | 签名 URL + 透传 headers |
| 谁发起 | 客户端 → 后端 | 播放器 → 115（**不经后端**） |

**硬原则：客户端永远不持有 115 长期凭据；后端不代理视频字节。**

---

## 5. 四条核心链路

### 5.1 检索链路
查询 → 并发调用各资源源 → 归一化 → 合并去重 → 排序 → 返回。

**输出是两层结构**：作品（Work）→ 候选（Candidate）。用户看到的是「一部剧有 7 个源可用」，
不是 7 条平铺结果。详见 [05](05-resource-search.md)。

### 5.2 落地链路
选中候选 → 执行动作（转存到 115 / 推送 / 下载）→ **异步任务** → 完成后探测 + 刮削 → 写入影视库。

转存是长任务，UI 必须能表达「处理中 / 成功 / 失败」，且不阻塞继续搜索。

### 5.3 播放链路
影视库条目 → 请求播放信息 → 服务端签发 115 直链 → 播放器直连拉流。
直链有有效期，客户端到期前主动刷新。

### 5.4 进度与收藏
**账号级**数据，存后端，Web 与 App 共享。这是双前端架构的直接收益。

## 7. 关键取舍

| 项 | 结论 | 原因 | 风险点 / 推翻条件 |
| --- | --- | --- | --- |
| 双前端并列 | Web 与 App 都是正式入口 | 桌面适合浏览管理，手机适合便携搜索与观看 | 两端 UI 易漂移 → Token 与语义色单一来源 |
| FastAPI + SQLite | 沿用 | Windows 单机零依赖 | 并发写入成瓶颈 → 迁 PG，仓储层已隔离 |
| 视频不落本地 | 115 直链 | 不占带宽与磁盘，天然多端 | 直链有效期与并发不可控 → 兜底可转存后本地播 |
| 转存作为落地主路径 | 主流路径 | 直接落到 115，之后即普通条目 | 频控与失败态 → 动作异步可观测，失败给可重试 |
| 搜索不强一致 | 允许部分失败 | 源异构，硬等最慢的源会拖死 | 用户误判「没有」→ 结果显式标 partial，UI 必须提示 |
| provider 可插拔 | 注册表 + 统一协议 | 资源源持续增删 | 抽象过厚拖慢接入 → 新源只实现少量方法 |
| 元数据刮削走外部源 | TMDB / 豆瓣等 | 自建库缺元数据 | 外部源可用性 → 结果落库缓存，失败不阻塞入库 |
| 进度存服务端 | 账号级 | 双端共享 | 离线看不到进度 → 客户端保留本地队列 |

# 09 · 品牌与视觉资产

> 唯一重点：**115REX 的品牌名、Logo、App 图标、字标、图标资产从哪来、按什么规格产出、怎么更新。**
> 色板、间距、圆角、字阶等**设计语言**归 [02](02-design-language.md)，本文只管**资产文件与规格**。
>
> **本篇是骨架**：定来源、规格与验收，不定具体路径曲线。

---

## 1. 品牌基准

| 项 | 内容 |
| --- | --- |
| 产品名 | **115REX** |
| 历史名 | RexHub —— **已废弃**，不再出现在任何界面、代码、资产文件名里 |
| 视觉基准 | 项目设计海报（蓝紫渐变、双色图标、大圆角、卡片化） |
| 品牌气质 | 清透、克制、轻盈、精致（详见 [02 §1](02-design-language.md)） |

**海报是视觉基准，但不是可交付资产**：它是位图概念稿，只能取色与取规格，不能直接导出切图。
所有资产必须以矢量重建，并纳入版本管理。

## 3. 打磨方向（不重新设计）

沿用海报已有的**双 R 飘带**造型与蓝紫渐变，只做工程化打磨：

| 项 | 要求 |
| --- | --- |
| 造型 | 保留飘带构成与切口走向，**不改整体结构** |
| 曲线 | 用连续贝塞尔重绘，消除位图描摹出的抖动与不等宽 |
| 光学 | 飘带粗细在转折处保持视觉等宽；拐角外圆内方一致 |
| 渐变 | 统一为 [02 §3.1.1](02-design-language.md) 的 `brandGradient` 停靠点，四段色标不随尺寸变化 |
| 安全区 | App 图标内符号占画面宽度约 60%，四周留足圆角裁切余量 |
| 小尺寸 | 缩到 40 仍能辨认两个飘带的层次，必要时出**简化版**（减一层切口） |
| 单色版 | 纯黑 / 纯白两版，靠形状而非渐变识别 |

**不做的事**：不换字标字体风格、不改品牌名、不引入第三种主色、不加投影与外发光。

## 4. 文件与命名

```
packages/brand/
├── svg/            母版：symbol / app-icon / wordmark-h / wordmark-v / mono-*
├── png/            导出位图，按用途分目录
└── README.md       每个文件的用途与生成命令
```

命名规则：`115rex-<资产>-<形态>[-<尺寸>].<ext>`，全小写，短横分隔。
例：`115rex-symbol-gradient.svg`、`115rex-app-icon-1024.png`。

- **SVG 是唯一母版**，PNG 一律由脚本从 SVG 导出，不手工另存。
- 旧品牌素材（RexHub）**只作造型参考**，不进入本目录，不参与构建。

---

## 5. 使用规则

| 场景 | 规则 |
| --- | --- |
| 启动页 | 横版字标居中，底用 `brandGradientSoft`；不放大到撑满屏幕 |
| 登录页 | 主符号 + 产品名，尺寸克制；不重复出现第三个 Logo |
| 导航栏 | **不放 Logo**（占空间且干扰标题层级） |
| 关于页 | 竖版字标 + 版本号 + 开源许可入口 |
| 加载态 | 用主符号做轻量呼吸动画，时长与缓动走 [02 §12](02-design-language.md) |
| 空状态 / 错误态 | 用主符号淡化版或线性插画，**弱于主操作** |
| 分享图 / 商店图 | 用竖版字标，背景用 `brandGradient` |

硬规则：

- Logo **不得**拉伸、加描边、加阴影、加外发光、旋转、改渐变方向。
- 渐变底上只用白色版；浅色底上用渐变版；深色底上用白色单色版。
- 最小尺寸：主符号 `24`，横版字标宽度 `96`。低于此尺寸改用主符号。

## 6. 与代码的衔接

| 层 | 落点 |

## 7. 验收

- [ ] 资产目录里**没有** RexHub 命名的文件
- [ ] 所有 PNG 都能由 SVG 一条命令重新导出，且与仓库内文件一致
- [ ] 主符号缩到 24 仍可辨认；App 图标缩到 40 仍可辨认
- [ ] 渐变停靠点与 `tokens.json` 完全一致，无第二份定义
- [ ] 单色版在纯黑与纯白底上都可用
- [ ] 浅色 / 深色两套界面里，Logo 都未被背景吞掉

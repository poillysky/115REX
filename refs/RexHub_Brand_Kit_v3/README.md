# RexHub Brand Kit v3 — traced from the supplied design board

The logo geometry in this version has been redrawn by tracing the visible silhouette of the RexHub mark in the supplied design-board image. The standalone symbol, app icon and wordmark reuse the same two ribbon paths and gradient system. PNG files are rendered directly from the SVG sources.

## Files
- `assets/brand/rexhub_app_icon.svg` / `.png`: app icon
- `assets/brand/rexhub_symbol.svg` / `.png`: standalone gradient symbol
- `assets/brand/rexhub_wordmark.svg` / `.png`: symbol + RexHub wordmark + tagline
- `reference/original_design_board.png`: original reference image for comparison
- `lib/design_system/rex_design_tokens.dart`: color, spacing, typography and theme tokens
- `lib/widgets/rex_primary_button.dart`: reusable primary button
- `lib/widgets/rex_surface.dart`: reusable surface/card

The reference is a raster concept image, so this is a careful manual vector reconstruction rather than a mathematically exact recovery of the original design source. SVG paths remain editable.

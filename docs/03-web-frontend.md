# 03 · Web 端规范

> 唯一重点：**Web 端这个界面应该怎么组织、怎么响应、怎么和 App 保持同一个产品。**
> 不涉及：iOS 系统层规则（[01](01-ios-essentials.md)）、通用设计语言（[02](02-design-language.md)）、
> 客户端分层（[04](04-app-architecture.md)）、接口字段（[07](07-api-contract.md)）。
>
> **本篇是骨架**：定 Web 端特有的布局与交互规则，视觉取值仍以 [02](02-design-language.md) 为准。

---

## 1. 定位

Web 端是**与 App 并列的正式入口**，不是管理后台的附属品。

| | Web 端 | App 端 |
| --- | --- | --- |
| 场景 | 桌面大屏、浏览与管理、多任务并行 | 单手操作、便携观看 |
| 导航 | 顶栏（全局信息）+ 侧栏（页面入口） | 底部 Tab（见 [02 §9.2](02-design-language.md)） |
| 密度 | 偏高（信息密度大，但不得拥挤） | 中低 |
| 手势 | 鼠标 + 键盘 | 触控 + 手势 |

**共用**：同一套后端契约、同一套 Token、同一套语义色与间距、同一套品牌资产。
**不共用**：导航形态、布局骨架、密度档位、组件实现。

视觉取值一律以 [02](02-design-language.md) 为准，本篇不重复色值。两端的品牌元素
（Logo、功能图标、渐变停靠点）来自同一份资产母版，见 [09](09-brand-assets.md)。

| 品牌元素 | Web 端形态 |
| --- | --- |
| 主符号 | 只在登录页与关于页出现；**导航内不放 Logo** |
| 功能图标 | 与 App 同一套 SVG，按 2x 内联，不另画一套 |
| 品牌渐变 | 仅用于登录页背景与播放页主控；导航与内容区不用渐变底 |
| 字阶 | 用 Token 字号，但可按 0.9 比例整体缩放，**不允许逐处调字号** |

## 2. 布局与响应式

| 要点 | 规则 |
| --- | --- |
| 内容最大宽度 | 正文区有上限（阅读型内容约 960px，网格型内容可更宽），超宽屏居中而非拉伸 |
| 断点 | 按「窄（手机）/ 中（平板）/ 宽（桌面）」三档，**不按设备型号** |
| 窄屏 | 单列；侧边导航折叠为顶部栏或抽屉 |
| 宽屏 | 影视库用网格 + 侧边筛选；搜索结果用「列表 + 详情」双栏 |
| 安全区 | 浏览器无刘海概念，但**窗口缩放与浏览器 UI 变化**要留出最小边距 |
| 文本缩放 | 浏览器缩放与系统字体放大都要能正常排版，不写死像素高度 |

## 3. 导航与页面骨架

| 页面 | 骨架 |
| --- | --- |
| 全局顶栏 | 左：Logo + 品牌名；中：全局搜索（搜索页隐藏，那里有页面自己的搜索框）；右：通知、日志、账号菜单（账号 / 退出） |
| 全局侧栏 | 页面入口唯一来源，一级按「内容 / 搜索 / 发现 / 115网盘 / 流程管理 / 系统」排列，带二级的一级可展开（当前页所属的一级自动展开）；宽屏常驻 216px，≤900px 折叠为抽屉，由顶栏菜单按钮唤出 |
| 内容 `/` | 首页：顶栏 + 侧栏 + 内容区；**当前为占位** |
| 搜索 `/search` | 侧栏 + 页面内常驻搜索框 + 结果区；宽屏「列表 + 详情」双栏 |
| 发现 `/discover` | 二级外壳（`SubShell`）：影视 `/movie`（影视库，真实页）/ 短剧 `/drama`（占位）/ 小姐姐 `/girl`（占位） |
| 115网盘 `/drive` | 二级外壳：文件浏览 `/files`（占位）/ 云下载 `/cloud`（占位） |
| 流程管理 `/flows` | 二级外壳：文件整理 `/organize`（占位）/ 自动化工作流 `/workflow`（占位）/ 动作记录 `/tasks`（真实页，顶栏「通知 / 日志」落这里） |
| 系统 `/system` | 二级外壳：115网盘管理 `/115` / 站点管理 `/sites` / 插件管理 `/plugins` / 用户管理 `/users`（占位）/ 设定 `/settings` |
| 系统-115网盘管理 `/system/115` | 分组列表 + 右侧说明；115 账号状态与到期时间 |
| 系统-站点管理 `/system/sites` | 资源源开关、转存偏好、图标库（可增删改排序） |
| 系统-插件管理 `/system/plugins` | 插件市场地址（多个，换行或逗号分隔）+ 插件热加载开关 |
| 系统-用户管理 `/system/users` | 自托管单账号模型；**当前为占位** |
| 系统-设定 `/system/settings` | 单页两个 tab：「系统设定」与「危险操作」，两者共用同一套卡片骨架（卡片头含标题与说明、卡身、底部动作条）。系统设定只放必需项，整块收进一张「基础设定」卡片：卡片头右侧是「高级配置」入口；卡身顶部三项必需配置并排一行（内网地址、反代地址（`bridgeUrl`，须带 http(s) scheme，留空表示未配置）、API 令牌（40 位十六进制，复制按钮与输入框合为一体），窄屏折为两列再折为一列）；过滤规则、豆瓣缓存、网络代理、请求超时与并发收在「高级配置」弹窗内。GitHub 配置与应用助手配置作为卡内折叠区块并入同一张卡片，收起时只占一行摘要（标题后跟状态徽标）。保存 / 重置配置位于卡片底部动作条（左状态文案、右两按钮，无改动时均禁用） |
| 系统-网络管理 `/system/settings/network` | 已并入「高级配置」弹窗（代理开关 + 带 scheme 的完整地址） |
| 系统-危险操作 `/system/settings/danger` | 只放不可逆操作（解绑网盘等），一律二次确认 |
| 候选详情 | 宽屏为右侧详情面板，窄屏为独立页 |
| 详情 / 播放 | 详情为内容页；播放为全屏，无导航 |
| 账号管理 `/account` | 头像、昵称、改密、服务器信息与退出；**入口只在顶栏账号菜单，不进侧栏** |

**规则**：导航位置在同类页面间保持一致；页面不自己造导航。
顶栏只承载**跨页面的全局信息**，页面入口一律放侧栏——两处都放入口会让「当前在哪」出现两个答案。
唯一例外是账号管理：它属于顶栏账号菜单，不进侧栏。
侧栏布局对齐 MoviePilot：一级常驻、二级跟随一级展开，当前页所属的一级始终展开且高亮（高亮按 `route.matched` 归属一级，详情页归到「发现」）。
带二级的一级用 `SubShell`（`title / sub / items` + `<RouterView />`）统一渲染，新增二级页 = 加一条子路由 + `items` 一行，不在各页复制导航样式。
功能未接入的页面统一用 `PlaceholderView`（`title / sub / item`）占位，接入后逐个替换，不保留长期占位。
内容区宽度由外壳统一限制（正文与网格 1280，搜索 1000，系统页 960），页面自身不再设宽度。

## 4. 搜索页（Web 端重点）

搜索是 Web 端最有价值的一屏（桌面适合浏览与对比）。

| 要点 | 规则 |
| --- | --- |
| 搜索框 | 常驻顶部；输入防抖；回车立即搜；保留最近搜索 |
| 结果结构 | **作品 → 候选两层**，作品为组标题，候选为组内条目（与契约一致，不拍平） |
| 候选信息 | 来源、画质、体积、完整度、可用动作；信息对齐，扫读友好 |
| 源筛选 | 可按资源源过滤；熔断 / 超时的源要**可见地标出来**（灰显 + 说明） |
| 部分结果 | `partial` 为真时顶部显示「部分资源源未响应」提示（硬要求，见 [07 §2.3](07-api-contract.md)） |
| 动作 | 转存按钮就地发起，动作状态就地更新（进行中 / 成功 / 失败），**不打断当前浏览** |
| 目标目录 | 转存前选目录（目录选择器见 [07 §2.5](07-api-contract.md)），记住上次选择 |
| 键盘 | `/` 聚焦搜索框，方向键在候选间移动，回车执行默认动作 |

## 5. 播放页

| 要点 | 规则 |
| --- | --- |
| 沉浸 | 全屏、无导航；控件出现 / 隐藏要明确 |
| 快捷键 | 空格播放暂停、←→ 快退快进、↑↓ 音量、`F` 全屏、`Esc` 退出 |
| 画质与字幕 | 可切换；切换后立即生效 |
| 进度 | 显示当前进度与剩余时间；拖动即时反馈 |
| 错误 | 区分「适配器未就绪」「地址失效」「网盘授权失效」，给对应下一步 |

## 6. 状态与反馈

Web 端的状态集合与 App 端一致（空 / 加载 / 错误 / 离线 / 无权限），但表现形式不同：

| 状态 | Web 端表现 |
| --- | --- |
| 加载 | 骨架屏优先于转圈；骨架尺寸与真实内容一致 |
| 空 | 说明 + 一个主要动作（例：「没搜到，试试换个关键词」+ 建议源） |
| 错误 | 说明原因 + 重试按钮；**不把错误码抛给用户** |
| 动作进行中 | 行内进度 + 取消；不弹模态遮挡结果 |
| 离线 | 顶部条提示，恢复后自动重试 |

## 7. 交互质感

| 要点 | 规则 |
| --- | --- |
| 按压反馈 | 悬停 / 焦点 / 按下三态清晰；动画短（100–200ms） |
| 焦点可见 | 键盘操作必须能看到焦点环，**不得 `outline: none`** |
| 悬停与点击区分 | 可点击元素在悬停时必须有变化，否则用户不知道能点 |
| 长耗时操作 | 转存、下载这类必须异步 + 就地状态，不做「转圈等结果」 |
| 右键 | 不用右键承载唯一功能；如提供，须有等价的可见入口 |

---

## 8. 与 App 的一致性检查

两端上线前对照：

- [ ] 同一状态在两端用同一语义色与同一措辞
- [ ] 同一术语（作品 / 候选 / 转存 / 刮削 / 入库）两端叫法一致
- [ ] 同一错误码两端给的下一步一致
- [ ] 深浅色两端的语义色映射一致
- [ ] 进度、收藏在两端读写的是同一份服务端数据

## 9. 技术形态（已定）

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 构建 | Vite 6 | `base` 保持默认，产物输出到 `apps/server/app/web/`，与后端同源托管 |
| 框架 | Vue 3.5 + TypeScript（strict） | `<script setup>` 单文件组件，`vue-tsc --noEmit` 纳入构建 |
| 路由 | vue-router 4 | history 模式，路由守卫按 `meta.public` 拦未登录 |
| 状态与数据 | Pinia 2（setup store） | 与 App 端共享同一套 Token 与进度语义，接口层只在 `data/` |
| 播放 | 原生 `<video>` | 直连播放信息接口返回的地址，不经后端中转字节 |
| Token | 从 `packages/design-tokens` 生成 | 生成物落 `apps/web/src/core/theme/`，**不手写色值** |
| 目录 | `apps/web/src/{core,domain,data,application,features}` | 与 App 端同名分层，见 [08 §2](08-fullstack-framework.md) |

开发期 `vite` 代理 `/api` → `http://127.0.0.1:9959`，生产期由后端静态托管同一份产物。
